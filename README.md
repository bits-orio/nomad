# Nomad

A mod for Factorio 2.1 with Space Age. Start on a small ship in orbit around Nauvis instead of crashing. Your mothership is your main base and research only works in space. Land on planets, mine, send resources up, and pull special floors and infinite sources out of rare deposits with the floor extractor.

**Download:** [Factorio Mod Portal](https://mods.factorio.com/mod/nomad) or the in-game mod manager.

Bugs and ideas: open an issue here or post in the Mod Portal discussion.
